## STEP 5 — INSTALL ALL DEPENDENCIES

If this is a monorepo with workspaces, run install from the **root** — not inside individual sub-folders:

```bash
npm install
# or if it uses pnpm:
pnpm install
# or yarn:
yarn install
```

If packages fail to install, read the error carefully — it's almost always a Node version mismatch or a missing peer dependency. Fix the root cause, don't just force-install.
