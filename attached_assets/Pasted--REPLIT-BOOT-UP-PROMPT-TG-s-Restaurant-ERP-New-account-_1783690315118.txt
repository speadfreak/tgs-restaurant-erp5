## WHAT THIS SYSTEM IS

TG's Restaurant (ቲጂ ምግብ ቤት) ERP is a **delivery-only** Ethiopian restaurant management system operating in Dubai, UAE. There is **no dine-in, no walk-in, no table service** — delivery only. It has five separate role-based portals all served from one backend and one PostgreSQL database:

| Portal | URL | Who uses it |
|---|---|---|
| Admin Command Center | `/` | Super Admin, Branch Manager |
| Chef Portal | `/chef` | Kitchen staff only |
| Deliveryman Portal | `/delivery` | Delivery staff only |
| Addis Ababa Portal | `/addis` | Ethiopia-based supply staff only |
| Customer Webapp | `/menu-public` | Public customers (no login needed) |
| Order Tracker | `/track/:code` | Public customers (no login needed) |

Each role can **only** access their own portal. Login auto-redirects by role. Enforced server-side — a chef JWT gets `403` on any admin API route regardless of what the frontend shows.

## STEP 1 — SET UP ENVIRONMENT VARIABLES

Open Replit's **Secrets** panel (lock icon in sidebar). Add every variable below. Never put secrets in `.env` files that get committed to the repo.

### Required to boot — system crashes without these:

| Secret Key | Value |
|---|---|
| `DATABASE_URL` | PostgreSQL connection string (set up in Step 2 first) |
| `JWT_SECRET` | Any random 64-character string |
| `JWT_REFRESH_SECRET` | A different random 64-character string |
| `SETTINGS_ENCRYPTION_KEY` | Any random 32-character string |
| `NODE_ENV` | `development` |
| `PORT` | `3000` |
| `FRONTEND_URL` | `http://localhost:5173` (for CORS — update this to deployed URL in production) |

### Required for full features — set to `placeholder` if not yet configured:

| Secret Key | Value |
|---|---|
| `TWILIO_ACCOUNT_SID` | `placeholder` |
| `TWILIO_AUTH_TOKEN` | `placeholder` |
| `TWILIO_WHATSAPP_NUMBER` | `placeholder` |

**After adding the above — scan the codebase for any other `process.env.` references:**

```bash
grep -r "process\.env\." artifacts/api-server/src --include="*.ts" | grep -v "//.*process"
```
Add anything found that isn't already in Secrets. A missing env var causes silent crashes.

## STEP 2 — SET UP POSTGRESQL DATABASE

1. In Replit → **Database** tab in sidebar → create a new PostgreSQL database → copy the connection string
2. Paste it as `DATABASE_URL` in Secrets
3. Push the schema (creates all tables):
```bash
pnpm run db:push
```
If that script doesn't exist at root level, try:
```bash
cd lib/db && npx drizzle-kit push
```
4. Seed demo data (staff accounts, branches, menu items, sample orders):
```bash
pnpm run db:seed
```
If that doesn't exist at root:
```bash
cd scripts && npx tsx src/seed.ts
```
5. Verify tables were created:
```bash
psql $DATABASE_URL -c "\dt"
```
You should see 20+ tables including: `users`, `orders`, `order_items`, `menu_items`, `menu_categories`, `branches`, `lottery_entries`, `lottery_draws`, `import_shipments`, `import_payments`, `suppliers_addis`, `settings`, `login_attempts`, `whatsapp_messages`, etc.

If you see fewer than 15 tables, the schema push failed — check the error and fix before continuing.

## STEP 3 — INSTALL DEPENDENCIES

This is a pnpm monorepo. **Always install from root — never cd into sub-folders and install separately.**

```bash
pnpm install
```

If pnpm is not available:
```bash
npm install -g pnpm && pnpm install
```

Node version must be **18 or higher**. If you get peer dependency errors, check Node version first:
```bash
node --version
```

Do not use `--force` to bypass errors. Read the error and fix the root cause.
